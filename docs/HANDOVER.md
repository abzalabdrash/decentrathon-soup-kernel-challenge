## Как вливать и мерить

1. Ветку подчата читать по отчёту (≤ 300 слов в его финальном сообщении и в `docs/notes/<задача>.md`), затем `git merge origin/<ветка>` в main; конфликты чаще всего в `docs/STATUS.md` (держать обе секции) и `solution/__init__.py` (докстринг переключателей).
2. Тесты: `wsl -d Ubuntu -- bash tools/wsl_pytest.sh solution` и `... soup` (79 тестов Soup с apply). На ноутбуке Абзала два теста падают от среды (bf16 на Blackwell): `test_cuda_limits`, `test_weight_ring::test_ring_switch_and_fallbacks`; на T4 проходят.
3. Kaggle (из WSL, kaggle ≥ 2.x, Python ≥ 3.11): `python tools/kaggle_run.py --user <namedesign|peagverr> --repo https://github.com/BAITC-Hacks/hack-78c6e9c3-null-pointers.git --commit <sha> --mode full|variants|jury|diag|bench --slug <уникальный>`; токен Kaggle в `KAGGLE_API_TOKEN`; токен GitHub лежит в приватном датасете `<логин>/soup-secrets` каждого аккаунта (уже создан). Два GPU-ноутбука на аккаунт одновременно. На ноутбуке Абзала обёртка `tools/kaggle_wsl.sh <1|2> ...` берёт токены с рабочего стола и держит слоты. Сравнивать варианты только внутри одной сессии (`--mode variants --abba --warm-run`): сессии различаются на ±10 %, первая в сессии быстрее по шагам и медленнее по старту.
4. После каждого влития: полный прогон (10 проверок) и прогон жюри на новых строках и seed (использованы: 7, 13, 21, 31, 42, 99, 123; строки 40000+ в eval публичные, `tools/jury_data.py` их отвергает); строка в таблицу STATUS; push.
5. Решения о направлении принимать по измерениям на T4, не по локальной карте и не по оценкам.

## Что нельзя

Не менять `harness/`, `tests/`, `task/`. Не менять задачу (модель, данные, порядок батчей, шаги, LoRA, оптимизатор, переключатели Soup, аллокатор, гиперпараметры). Запрещены: готовые библиотеки ядер, CUDA graphs для своих ядер, torch.compile как «свои ядра», `sys.modules`-заглушки, `os._exit`, фоновые процессы (потоки можно), кэши между прогонами, общая маска для метрик. Каждый патч откатывается на оригинал при неожиданном входе. `runs*/` и токены в репозиторий не класть.
