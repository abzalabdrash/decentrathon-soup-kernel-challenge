3. Kaggle (из WSL, kaggle ≥ 2.x, Python ≥ 3.11): `python tools/kaggle_run.py --user <namedesign|peagverr> --repo https://github.com/BAITC-Hacks/hack-78c6e9c3-null-pointers.git --commit <sha> --mode full|variants|jury|diag|bench --slug <уникальный>`; токен Kaggle в `KAGGLE_API_TOKEN`; токен GitHub лежит в приватном датасете `<логин>/soup-secrets` каждого аккаунта (уже создан). Два GPU-ноутбука на аккаунт одновременно. На ноутбуке Абзала обёртка `tools/kaggle_wsl.sh <1|2> ...` берёт токены с рабочего стола и держит слоты. Сравнивать варианты только внутри одной сессии (`--mode variants --abba --warm-run`): сессии различаются на ±10 %, первая в сессии быстрее по шагам и медленнее по старту.
