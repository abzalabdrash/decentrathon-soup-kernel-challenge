## Итог

Ни один рычаг не проходит GO (≥ −0,2 с): INT8_WARMUP переносит ~2,5–3 с компиляции на критический путь прогрева (выигрыш на шагах 1–5 −0,25 с, потеря на старте +0,65…+1,1 с); с ним int8 forward не возвращается (+2,6…+3,2 с прогрева). ATTN_GLUE на публичных строках 0 (+0,15 с, шум). Компилировать int8-ядра выгодно только там, где у CPU есть простой: в своих потоках на шагах (как сейчас, ~+0,2…0,4 с) или в прогреве, если он станет короче начала обучения с запасом (зона L2). Ветка остаётся для справки, не вливать.
